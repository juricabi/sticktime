              How to use on the radio
              1. Each slot, c1 to c8, is the same track number on the emulator and on the radio. Send to emulator puts the track in the emulator's slot and Fly c1 flies that slot here; Send to radio puts it in the radio's; Save file downloads it as c1.txt (the slot's number).
              2. Copy the file to /SCRIPTS/TOOLS/StickTimeTracks/ on the radio's SD card (the folder is in the release zip; make it if it's missing). In Chrome or Edge on a computer, Send to radio does it for you: the radio plugged in by USB, in USB Storage mode. On the hosted site, Install (next to Tracks) also installs or updates the game. Eject the drive before you unplug the radio, and restart StickTime on it to see a new track.
              3. Up to 8 tracks, c1.txt to c8.txt: they come after the 8 built-in ones in the track menu, by name (tracks 9 to 16).
              4. StickTime and StickTime BW read them; StickTime Lite doesn't.
              5. Best times and the ghost are kept while the track stays the same: any change to its gates, structures or trees starts them over (renaming it doesn't); so does putting it in another slot.

              Install / update StickTime

              To install StickTime, copy the SCRIPTS folder of the SD card zip to the card's top level, from the latest release; the emulator at juricabi.github.io/sticktime can install it for you.

                Thanks for flying StickTime! If you like it, you can buy me a coffee on Ko-fi.

                Faster firmware optional, color radios

                Stock EdgeTX runs a tool at most every 50 ms (20 fps) and shows each frame a cycle late. The fast-lua-20ms build (EdgeTX main with StickTime's fast-lua patch) runs Lua tools every 20 ms and shows each frame at once: up to 50 fps on the HelloRadioSky V12, about 40 ms from stick to screen.

                1. Download the firmware for your radio from the fast-lua-20ms release: tx16s for the TX16S and MkII, tx16smk3 for the MK3, and so on.
                2. Back up your SD card: these are test builds.
                3. Flash it like any EdgeTX update: copy it to the SD card's FIRMWARE folder and write it from the bootloader, as EdgeTX's manual shows (the TX16S MK3 and other STM32H7 radios are flashed differently: see STM32H7 radios).

                To go back, flash a stock EdgeTX release the same way.

                Emulation
                
      
                
        
        
        
        
      
                
      
                The radio calls a tool script's run() at most every 50 ms, so the sim is built for 20 fps. Color radios show each frame one 50 ms cycle after it is drawn; the script renders the view where the quad will be by then.
