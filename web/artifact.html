Emulation

      

        
        
        
        
      

      
The radio calls a tool script's run() at most every 50 ms, so the sim is built for 20 fps. Color radios show each frame one 50 ms cycle after it is drawn; the script renders the view where the quad will be by then.

    

  






  Runs the real EdgeTX scripts in a Lua 5.3 VM (fengari, MIT). LCD text uses Roboto (OFL) like color radios, and the public-domain X11 fixed fonts for B&W screens. Idea inspired by lua-fpv-sim by Alexey Stankevich.
