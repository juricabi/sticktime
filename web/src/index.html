          How to use on the radio
          1. Save file downloads the track as c1.txt (the slot's number).
          2. On the radio's SD card, make the folder /SCRIPTS/TOOLS/StickTimeTracks/ and copy the file into it. In Chrome or Edge on a computer, Connect radio and Send to radio do both: the radio plugged in by USB, in USB Storage mode.
          3. Up to 8 tracks, c1.txt to c8.txt: they come after the 8 built-in ones, as tracks 9 to 16 in the track menu.
          4. StickTime and StickTime BW read them; StickTime Lite doesn't.
          5. Best times are kept while the track stays the same: any change to it starts them over.

          Emulation
          
      
          
        
        
        
        
      
          
      
          The radio calls a tool script's run() at most every 50 ms, so the sim is built for 20 fps. Color radios show each frame one 50 ms cycle after it is drawn; the script renders the view where the quad will be by then.
